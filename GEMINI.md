# Product Metrics

Product Metrics sends every paid order from an online store to Google Ads, Meta and ChatGPT Ads from the server, with its revenue, profit, new or returning customer and lifetime value, so campaigns can bid on profit. Use the `product-metrics` MCP server tools for setup and analysis.

For a setup task, read the skill for the store platform and ad channel in this extension's `plugins/<plugin>/skills/` folder, starting with `plugins/product-metrics/skills/product-metrics/SKILL.md`, which routes to the right one. Docs: https://www.productmetrics.io/docs (Markdown index: https://www.productmetrics.io/docs/llms.txt).
